## 🌟 How to Upload to GitHub in 3 Steps

1. Go to **[github.com](https://github.com/)** and click the green **"New"** button to create a new repository.
2. Name the repository: `bindu-portfolio`, choose **Public**, and click **"Create repository"**.
3. On the setup screen, click the link: **"uploading an existing file"**.
4. Open `E:\myportfolio\bindu-portfolio-github` in File Explorer.
5. Select all files and folders inside `bindu-portfolio-github` (press `Ctrl + A`).
6. **Drag and drop** them into your GitHub browser window.
7. Wait 5–10 seconds for the files to attach, then click the green **"Commit changes"** button at the bottom.

> ✅ **Result**: GitHub will accept the upload cleanly because there are **only 86 files** (under the 100-file limit) and **no file exceeds 5MB** (well under the 25MB limit).

## ⚡ How to Deploy on Vercel in 60 Seconds

1. Go to **[vercel.com](https://vercel.com/)** and log in with your GitHub account.
2. Click **"Add New..."** &rarr; Select **Project**.
3. You will see `bindu-portfolio` listed. Click **"Import"**.
4. Leave all settings at default (*Next.js preset and build settings are pre-configured in `vercel.json`*).
5. Click **"Deploy"**.

In approximately 60 seconds, your site will be live worldwide with free SSL at:
👉 `https://bindu-portfolio.vercel.app`
